# Glade x402 payments

The [REST API](rest-api.md) endpoints support [x402](https://x402.org) — a standard for per-call USDC payments on Base. No API key or account required. x402-compatible agents receive a `402 Payment Required` response, pay automatically, and retry.

x402 covers the REST endpoints only. The [MCP server](../README.md) uses API keys.

| Endpoint | Cost |
|---|---|
| `GET /api/v1/locations/search` | $0.0010 USDC (1 credit) |
| `GET /api/v1/locations/:id` | $0.0030 USDC (3 credits) |

## Flow

```bash
# 1 — request without auth returns 402 with payment instructions
curl -s https://getglade.co.uk/api/v1/locations/search?postcode=WA14+4SA
# → HTTP 402  { "x402Version": 1, "accepts": [...payment requirements...] }

# 2 — x402 client pays and retries with signed X-PAYMENT header
# (handled automatically by x402-compatible agents and SDKs)
```

## Clients

Any x402-compatible client handles the `402` → pay → retry loop for you. It signs payments with a wallet you control, so Glade never sees your keys. To set one up, see Coinbase's [x402 buyer quickstart](https://docs.cdp.coinbase.com/x402/buyer/quickstart), which covers TypeScript and Python clients.

Glade currently serves x402 **version 1** (`"x402Version": 1` in the 402 response). The quickstart uses the v2 packages, so check that your client supports v1 payment requirements.

Payments settle on Base mainnet. For testing use `base-sepolia` (configured server-side).
